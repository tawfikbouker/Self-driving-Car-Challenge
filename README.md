# Self-driving-Car-Challenge
A battery-powered self-driving car with a fiberglass base, gearbox, and an AI camera )HUSKYLENS - AI Camera For Arduino( mounted on top of the car, along with a distance sensor and a color sensor in the front to determine the desired path. All these components were connected to an Arduino device.
